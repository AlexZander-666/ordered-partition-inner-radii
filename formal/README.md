# Sharp inner radii for ordered set partitions

For each fixed block threshold j ≥ 4, the minimum complex root distance to 1 tends to C and the minimum distance to 0 tends to C−1. The original row counts ordered set partitions with every block of size at least j carrying the marker. The constant C is the ratio at the unique positive critical maximum a between log 2 and 1. The set of roots is nonempty for all sufficiently large n. The Lean statement uses the metric distance to that entire set.

The coefficient theorem establishes locally uniform convergence of the normalized original rows to sin(√u)/√u, defined by its entire series. The nearest-root theorem combines real sign changes of that limit with a subcritical zero-free disk for all complex roots. It applies without an assumption of real-rootedness.
