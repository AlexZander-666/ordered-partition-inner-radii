# A linear proportion of strictly interlacing smallest roots

For every fixed threshold j at least two and every fixed maximum row gap H, there is c>0 such that for every sufficiently large n the first floor(c n) roots of the original row, ordered by absolute value among all complex roots, are simple and negative. The rows n and n+h strictly interlace within this prefix for 1≤h≤H. The proof includes full-complex-plane exclusion, simplicity in the original row, orientation, and exhaustion of the first ranks. The result leaves the remaining roots unrestricted.

The entry module is OrderedPartitions.CriticalEdgeLinearPrefix. Run python3 -Bu verify.py /absolute/path/to/locked/Lake/packages 3 from a clean extraction. External Lean and Mathlib checkouts are version locked. See modules.txt and audit-names.txt for the exact verification scope.
