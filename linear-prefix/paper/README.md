# A linear fraction of interlacing inner zeros in ordered set partitions

Internal author edition. The source archive contains the complete proof
and builds with TeX Live 2026. It contains the manuscript sources and the
LaTeX replay script. The Lean proof is distributed in a separate archive.

Run the following from a fresh extraction of the TeX source ZIP.

    python3 reproduce.py --output main.pdf --log build.log

Set PDFLATEX to the full path of the executable if it is absent from PATH.
The script runs two passes from a fresh directory with a fixed PDF creation
date. Compare the SHA-256 against the recorded author-edition manifest.
