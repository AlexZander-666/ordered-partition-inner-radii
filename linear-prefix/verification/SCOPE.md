# Scope of the linear-prefix result

The top formal theorem proves a positive linear prefix over the whole
complex zero set of the original ordered and labelled rows. It includes
simplicity, global modulus ordering and the two strict inequalities for
any fixed finite row-gap bound. The optional upper bound on the fraction
c in the paper follows by shrinking the positive witness.

The threshold-three isolation route in Lean uses the established root
arrays and an independent critical-point argument. The paper uses a
circle comparison. The final fixed-index estimate is a paper corollary.
The reviewed source and the complete Spark cold-verification package
contain the same original Lean source bytes. The paper is a separate
preprint from the companion fixed-window sinc and nearest-distance study.
